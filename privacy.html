Privacy Policy

Asistent · Last updated: 4 November 2026 · Home

Who operates Asistent

Asistent is a private, self-hosted application operated by Ivo Klčo (Slovakia) for personal use only. Contact: skounnn@gmail.com. The only users are the operator's own Google accounts. It is not offered to the public.

What Google data it accesses

  • Gmail (read-only): messages and attachments, to find invoices, payment requests and due dates.
  • Google Calendar: reading existing events, and creating reminder events only in a dedicated calendar named “Asistent”.
  • Google Contacts (read-only): names and dates, to recognise senders and show name days.

Asistent never sends, modifies or deletes email, never changes other calendars, and never makes payments.

How the data is used

The data is used only to show the operator a personal overview of bills, deadlines and reminders. Short excerpts of email text may be sent to the Anthropic API (Claude) to extract amounts and due dates; the model has no tools and the results are checked against the original text. Anthropic does not use API data to train models.

Storage and security

Data is stored on a private server in Germany (Hetzner, Falkenstein), reachable only over a private network (Tailscale) and protected by the owner's password. OAuth tokens are stored only on that server, in a file readable only by the application, and are never logged or committed to source code.

Sharing

Google user data is not sold, not shared with third parties and not used for advertising. The only processor is the Anthropic API as described above.

Google API Services User Data Policy

Asistent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data is kept only as long as needed for the overview. Access can be revoked at any time at myaccount.google.com/permissions; after revocation no new data is read. Stored data is deleted on request sent to the contact address above.
